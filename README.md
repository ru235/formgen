# formgen

Генератор точных чертежей коробок (dieline) по каталогам FEFCO и кастомных
конструкций. Сервис привлекает клиентов в штанцбюро: бесплатный точный
чертёж → мгновенный расчёт штанцформы в ₽ → заявка на изготовление
вырубного штампа / штанцформы.

- **Домен:** formgen.ru
- **Аудитория:** типографии и гофрообработчики
- **MVP:** FEFCO **0427** (вырубная самоблокирующаяся коробка) и **0215** (slotted, snap-bottom 1-2-3)
- **Экспорт:** PDF 1:1 мм (заказчик) + DXF R12 со слоями CUT/CREASE/PERF/GLUE (штанцбюро)
- **Стек:** статика + TS-engine в браузере (SVG-превью) + PHP-эндпоинт (экспорт, заявки)

## Что решает

Типография или гофрообработчик получает:

- точный разворот коробки за минуту: внутренние размеры L×B×H, тип материала,
  sizeMode (Inside / Folding lines / Outside);
- файл сразу в производство — слои реза, биговки, перфорации и клея разделены;
- расчёт штанцформы: (Σрез + Σбиговка) × 1600/1700 ₽/п.м. + (Σперфорация + Σклей) × 500 ₽/п.м.;
- заявку в штанцбюро в один клик.

## Источники стандартов

- FEFCO Code, 12th edition (2022) — бесплатный интерактивный PDF с fefco.org
- FEFCO Common Footprint Quality (CFQ) Standard — замки для группы 04
- Сверка эталонных чертежей с реальными штампами штанцбюро (обязательна)
